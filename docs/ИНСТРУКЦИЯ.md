# Джарвис — инструкция

**Джарвис** — голосовой помощник для Windows. Ты говоришь «Джарвис, открой ютуб», и он открывает. Он умеет
включать музыку, закрывать окна, открывать файлы, искать в интернете, ставить таймеры и просто болтать.
Работает **без интернета** (интернет нужен только для установки, погоды и поиска). Ничего программировать не надо.

> Эту инструкцию всегда можно открыть: **значок у часов → «Инструкция»** или **Пуск → Джарвис → Инструкция**.
> Версия инструкции: 1.0.9.

## 1. Быстрый старт за 5 минут

**Шаг 1. Скачай установщик.**
Нажми на ссылку: **[скачать JarvisSetup.exe](https://github.com/kravakos13/jarvis-voice-assistant/releases/latest/download/JarvisSetup.exe)**
(это всегда последняя версия). Файл весит около 15 МБ.

* Если браузер пишет «Этот файл обычно не скачивают» — нажми **«…» → «Сохранить» → «Всё равно сохранить»**.
  Так браузер говорит про любые новые программы, это нормально.

**Шаг 2. Запусти установщик.**
Открой скачанный файл `JarvisSetup.exe` (обычно он в папке «Загрузки»).

* Если появилось синее окно **«Windows защитил ваш компьютер»** — нажми **«Подробнее»**, потом
  **«Выполнить в любом случае»**. Это предупреждение показывается для программ без платной подписи.
* Пароль администратора **не нужен**.
* В установщике просто жми **«Далее»**. Галочки по умолчанию правильные:
  * «Ярлык на рабочем столе» — оставь;
  * «Запускать Джарвиса вместе с Windows» — по желанию;
  * «Скачать голос, распознавание речи и ИИ» — **обязательно оставь**.
* Потом откроется чёрное окно с процентами — это скачиваются голос, распознавание речи и ИИ (около 6–7 ГБ).
  На быстром интернете **10–20 минут**, на медленном дольше. Окно не закрывай. Компьютером пользоваться можно.
* Если что-то не скачалось (оборвался интернет), окно напишет об этом простыми словами. Ничего страшного:
  Джарвис сам предложит докачать при запуске.

**Шаг 3. Первый запуск.**
В конце установки Джарвис запустится сам (или открой ярлык «Джарвис» на рабочем столе).

* Появится окно с лицом, а **справа внизу, возле часов, — значок: голубое кольцо с точкой в центре**. Если значка
  не видно, нажми стрелочку **^** возле часов. Красное кольцо — микрофон на паузе.
* Первые **30–60 секунд** он загружает модели. Когда на лице написано **«СПЛЮ»** — он готов и ждёт своего имени.
* Если ИИ ещё не скачан (например, оборвался интернет), Джарвис **сам начнёт загрузку** — полоска прогресса
  над полем ввода. При обрыве он докачает с того же места.
* Если не установлена программа Ollama (она нужна для ИИ), Джарвис спросит «Установить её сейчас?» — нажми **«Да»**.

**Шаг 4. Проверь.**
Скажи обычным голосом: **«Джарвис, привет»**. Он ответит голосом. Потом попробуй **«Джарвис, который час?»**.
Если он отвечает — всё работает 🎉 Не отвечает — смотри раздел [Что-то не работает](#8-что-то-не-работает).

**Шаг 5. Десять самых полезных команд.**

| Скажи | Что будет |
|---|---|
| Джарвис, открой ютуб | откроется YouTube |
| Джарвис, включи Imagine Dragons | музыка в YouTube Music |
| пауза / продолжи | пауза и продолжение (имя не нужно) |
| закрой | закроет окно, которое впереди (игры — никогда) |
| Джарвис, открой файл отчёт | найдёт файл на компьютере и откроет |
| найди в хроме рецепт борща | поиск в браузере (имя не нужно) |
| Джарвис, поставь таймер на 10 минут | таймер со звонком |
| громче / тише | громкость (имя не нужно) |
| стоп | пока Джарвис думает — отменить ответ |
| Джарвис, давай поболтаем | разговор без имени, пока не скажешь «пока» |

## 2. Что нужно компьютеру

* **Windows 10 или 11**, 64 бита.
* **Оперативная память:** 16 ГБ. С 8 ГБ тоже работает — выбери нагрузку «Лёгкая» (см. [Настройки](#6-настройки-простыми-словами)).
* **Место на диске:** около 10 ГБ.
* **Микрофон** — любой: в наушниках, веб-камере или отдельный.
* **Интернет** — только для установки, обновлений, погоды и поиска.
* **Видеокарта NVIDIA на 6 ГБ и больше** — по желанию. С ней ИИ отвечает за 1–3 секунды, без неё — медленнее, но всё
  работает. (Видеокарта — это отдельная плата для графики; в играх она главная.)

Что такое **«модель» и «ИИ»** в этой инструкции: это «мозг» для разговора, большой файл (~5 ГБ), который работает
прямо на твоём компьютере через бесплатную программу **Ollama**. Простые команды («пауза», «закрой») работают и без
него, мгновенно.

## 3. Как говорить с Джарвисом

**Главное правило: сначала имя, потом просьба.** «Джарвис, открой стим». Без имени Джарвис спит и разговоры в
комнате не слушает.

* Можно сказать только **«Джарвис»** — он ответит «Слушаю» и выслушает **одну** просьбу.
* Говори обычными словами. Падежи, ошибки, «Жарвис», «ютюб» он понимает.
* Если Джарвис спросил «да или нет?» — отвечай без имени.
* На лице видно, что он делает: **СПЛЮ / СЛУШАЮ / ДУМАЮ**.
* Пока Джарвис говорит, он тебя не слышит (свой голос он не принимает за команду).

### Команды без имени

Короткие команды можно говорить **без «Джарвис»**: «пауза», «громче», «закрой», «вторая вкладка», «найди в хроме
котиков». Чтобы он не срабатывал на обычную речь, такая команда выполняется, только если:

* вся фраза — это команда, причём короткая (для поиска — до 15 слов запроса);
* она сказана чётко и не во время речи Джарвиса;
* в ней нет опасного: выключить компьютер, закрыть игру — **только с именем и после «да»**.

Без имени Джарвис отвечает **молча**. Разговор, заметки, напоминания, Telegram — только с именем. В таблицах ниже
колонка **«Без имени»** показывает, что так можно.

Выключить: **значок у часов → Настройки… → Основные → «Команды без имени»**. Там общий переключатель и галочки
по группам: музыка и видео, видео по номеру, назад/вперёд, вкладки, окна, проводник, клавиши, набор текста,
открой/закрой, «включи <песню>», умный дом, **поиск**.

### Как остановить Джарвиса

* **Пока он думает** (или сказал «Секунду»), скажи **«стоп»**, «отмена», «хватит», «забей» или «не надо». Он бросит
  ответ и скажет «Ок, отменил». Другие слова в это время он пропускает.
* **Пока он говорит**, голос он не слышит. Нажми **`Ctrl+Alt+X`** или **значок у часов → «Остановить»**.
* В другое время «стоп» значит «пауза» для музыки и видео.

### Режим беседы

Скажи **«Джарвис, давай поболтаем»** (или «расскажи анекдот», «как дела»). Дальше говори без имени, как с
человеком. Закончить: «хватит болтать», «пока», «спасибо, всё» или просто помолчи ~22 секунды.

### Другие способы

| Сочетание клавиш | Что делает |
|---|---|
| `Ctrl+Alt+Пробел` | держи и говори — имя не нужно |
| `Ctrl+Alt+X` | остановить: замолчать и бросить ответ |
| `Ctrl+Alt+M` | микрофон на паузу / включить (на паузе звук вообще не записывается) |
| `Ctrl+Alt+J` | показать / спрятать окно |
| `Ctrl+Alt+G` | держи и спроси про игру на экране |
| `Ctrl+Alt+D` | диктовка в любое окно вкл / выкл |

Можно и **писать** в поле внизу окна Джарвиса. Сочетания меняются в **Настройки… → Микрофон**.

## 4. Самое нужное: что он умеет

Здесь — обычными словами. Полные таблицы — в следующем разделе.

### Окна и программы

* **«Открой стим»**, «открой калькулятор» — запускает программы и игры.
* **«Закрой»** (или «закрой это / окно») — закрывает окно, которое было впереди, когда ты начал говорить. Если
  впереди был сам Джарвис — то окно, где ты был до него. В браузере закрывается всё окно, а **«закрой вкладку»** —
  одна вкладка.
* **«Закрой хром»**, «закрой калькулятор», «закрой параметры» — по названию. Приложения Windows (Калькулятор,
  Параметры, Фото, Медиаплеер, Store, Терминал) тоже закрываются.
* **«Закрой весь проводник»**, «закрой все окна хрома», «закрой весь ютуб» — все окна (или все вкладки ютуба)
  сразу. Джарвис скажет, сколько закрыл: «Закрыл 4 окна проводника». «Закрой все окна» — все окна программы,
  которая впереди.
* **Программы у часов** (Steam, Discord, Telegram, Epic, WiFi Mouse) по команде «закрой стим» **выходят
  полностью**. Если сейчас идёт игра из Steam, Джарвис сначала спросит. Если программа не закрывается, он спросит
  «Убить процесс?».
* Если окно просит сохранить изменения, Джарвис его не трогает и говорит: «Просит сохранить — ответь в окне».
* **Игры Джарвис сам не закрывает никогда.** Закрыть игру можно только так: «Джарвис, закрой киберпанк» (по
  названию) или «Джарвис, закрой игру» — и подтвердить «да». Рабочий стол, панель задач, системные окна и себя
  он тоже не закрывает. Свой список «не закрывать» — в **Настройки… → Основные → «Закрытие окон»**.

### Браузер и вкладки

* **«Вторая вкладка»**, «на третью вкладку», «вкладка пять», «перейди на пятую вкладку», «последняя вкладка».
  Работает с любым номером. Если впереди браузер, можно сказать просто **«третья»**.
* «Новая вкладка», «закрой вкладку», «верни вкладку», «обнови», «листай вниз».
* **«На весь экран»** — браузер на весь экран (как клавиша F11).

### YouTube и музыка

* «Включи Imagine Dragons», «пауза», «продолжи», «следующий трек», «громче».
* **«Полный экран»** (или «разверни видео») — видео на весь экран. **«Обычный экран»** (или «малый экран»,
  «сверни видео») — обратно. Повторная команда ничего не ломает.
* **«Кинотеатр»** — широкий плеер, **«мини-плеер»**, **«субтитры»**.
* Просто «сверни» по-прежнему сворачивает окно.

### Файлы

* **«Джарвис, открой файл отчёт за март»** — ищет файл по имени на компьютере. Сначала смотрит рабочий стол,
  документы, загрузки и открытую папку проводника. Понимает и «хэллоу» вместо «hello», и цифры («открой файл 1111»).
* Нашлось несколько — Джарвис назовёт три. Скажи **«второй»** (имя не нужно).
* **«Открой папку проекты»** — папку по имени. «Открой загрузки», «открой документы» — стандартные папки.
* Без имени «открой файл …» работает, только если такой файл точно есть.

### Поиск в интернете

* **«Найди в хроме …»**, «найди в гугле …», «загугли …», «найди на ютубе …» — открывает поиск. Работает и
  **без имени**, но только с этими словами («в хроме», «в гугле», «в интернете», «на ютубе», «загугли»).
* **«Джарвис, найди в интернете …»** с именем — Джарвис сам прочитает ответ и покажет ссылки.

### Клавиши и текст

* «Нажми энтер», «нажми контрол цэ», «альт таб» — нажимает клавиши в твоём окне.
* «Напиши привет, как дела» — печатает текст. «Пиши» — диктовка.

### Остальное

* **«Посчитай 15 процентов от 200»**, «сколько будет 7 умножить на 8».
* «Поставь таймер на 5 минут», «напомни через 20 минут проверить духовку», «запиши заметку …».
* «Какая погода», «есть ли тревога», «громкость 40», «скриншот».
* **«Собери диагностику»** — архив с логами на рабочий стол (если что-то не так).

## 6. Настройки простыми словами

Все настройки открываются так: **правый клик по значку у часов → «Настройки…»**. Всё мышкой, файлы править не
надо. Внизу кнопки «Сохранить», «Отмена» и «По умолчанию». Если нужен перезапуск, Джарвис скажет.

| Вкладка | Что там простыми словами |
|---|---|
| Основные | как обращаться, приветствие, **команды без имени** (с галочками по группам), **режим беседы**, **«Закрытие окон» → «Не закрывать»** (программы, которые Джарвис не трогает), **нагрузка на компьютер**, автозапуск |
| Голос | какой голос, скорость, громкость. Кнопка «Прослушать» |
| Микрофон | какой микрофон (полоска прыгает, когда говоришь), чувствительность, **сочетания клавиш** (в т.ч. «Остановить») |
| ИИ | какая модель, кнопка «Скачать», **«Где работает ИИ»** (видеокарта — быстро; оперативка — медленно), длина ответов, характер |

### Нагрузка на компьютер

**Настройки… → Основные → «Нагрузка на компьютер».**

| Нагрузка | Для кого | Что происходит |
|---|---|---|
| **Обычная** (по умолчанию) | почти для всех | ИИ остаётся в памяти и отвечает быстро; в игровом режиме выгружается, чтобы не мешать игре |
| **Лёгкая** | 8 ГБ памяти, слабый ПК, игры | ИИ поменьше (~2 ГБ), ответы проще; выгружается через 5 минут простоя |
| **Максимальная** | мощный ПК | все ядра процессора, обычный приоритет |

Если памяти мало, Джарвис **скажет об этом**, а не будет молча тормозить компьютер.

### Где работает ИИ

**Настройки… → ИИ → «Где работает ИИ».** «Видеокарта» — быстро (по умолчанию). «Оперативка» — освобождает
видеокарту, но ответы в 3–5 раз медленнее. «Авто» — видеокарта, а в играх оперативка.

> В 1.0.9: если раньше там стояло «Оперативка» (часто так делали, когда в 1.0.7 была ошибка), Джарвис один раз
> вернул «Видеокарта» и написал об этом. Хочешь оперативку — выбери её снова, больше он не тронет.

### Лицо, голос, автозапуск

* **Лицо и цвет:** Настройки… → Интерфейс.
* **Голос:** Настройки… → Голос, кнопка «Прослушать».
* **Автозапуск с Windows:** галочка в меню значка у часов, или «Джарвис, включи автозапуск».

### Люмо (письмом)

«Передай Люмо …» отправляет задачу облачному ассистенту Люмо **письмом** (адрес меняется в
«Настройки → Интеграции → Люмо»). Перед отправкой Джарвис зачитывает суть и спрашивает **«Отправить?»**. Без
«да» ничего не уходит. Способы отправки:

1. **Google (Gmail)** — кнопка «Подключить Google», вход в браузере. Джарвис может только **отправлять** письма,
   читать твою почту он не может.
2. **Почта SMTP** — свой Gmail и **пароль приложения** (myaccount.google.com → Безопасность → Пароли
   приложений). Кнопка «Проверить вход» ничего не отправляет.
3. **Webhook** — для опытных.

Пароли и ключи хранятся в «Диспетчере учётных данных» Windows, а не в файлах.

### Синхронизация между компьютерами

«Настройки → Бэкап и синхронизация»: выбери **общую папку**, которая синхронизируется сама. Например, папку
«Google Диск» программы Google Drive для компьютера, OneDrive, Dropbox, сетевую папку или флешку. Джарвис сам
предложит найденные папки облаков. Потом жми **«Синхронизировать»** (или скажи «синхронизируй») на каждом ПК.

* Синхронизируются заметки, задачи, память, характер, псевдонимы игр, цвет и режимы.
* Не синхронизируются микрофон, устройства, горячие клавиши и **все пароли**.
* Если заметку меняли на двух ПК, вторая версия сохранится рядом с пометкой «конфликт».
* Можно включить автосинхронизацию при запуске и выходе.

Прямой синхронизации через Google-аккаунт (без программы Google Drive) пока нет: вход Google сейчас нужен только
для писем Люмо.

## 7. Обновление

Раз в день Джарвис сам проверяет, не вышла ли новая версия. Если вышла — появится окно со списком изменений и
кнопками **«Установить сейчас / Позже / Пропустить»**. Без твоего «да» ничего не обновляется.

* Проверить вручную: **значок у часов → «Проверить обновления»**.
* Или скачай установщик по той же ссылке из шага 1 и запусти поверх.
* Настройки, заметки, задачи, память и устройства **сохраняются**.

## 8. Что-то не работает

**Сначала скажи «Джарвис, проверь себя»** (или значок у часов → «Самодиагностика»). Он проверит микрофон,
распознавание, ИИ, голос и интернет, а у проблем покажет кнопку **«Исправить»**.

**Не слышит меня.**
1. Посмотри на значок у часов: если кольцо **красное** — микрофон на паузе. Нажми `Ctrl+Alt+M`.
2. **Настройки… → Микрофон**: выбери свой микрофон. Скажи что-нибудь — полоска уровня должна прыгать.
3. В шумной комнате поменяй «Чувствительность».
4. Не помогло — значок у часов → **«Перезапустить прослушку»**.

**Выбран не тот микрофон.**
Настройки… → Микрофон → выбери нужный из списка → «Сохранить». В Windows проверь «Параметры → Система → Звук →
Ввод», что микрофон включён и не отключён в конфиденциальности («Параметры → Конфиденциальность → Микрофон»).

**Медленно отвечает.**
* Простые команды (окна, музыка, клавиши, громкость) мгновенные. Думать может только разговор с ИИ.
* В 1.0.9 исправлено: Джарвис больше не заставляет ИИ работать без видеокарты. После запуска в логе есть строчка
  вида **«ИИ qwen2.5:7b: 25/29 слоёв на GPU»** — это значит, что видеокарта работает. Если там **«0/29»**,
  Джарвис покажет предупреждение: обнови программу **Ollama** (ollama.com) и драйвер NVIDIA (nvidia.com).
* Проверь **Настройки… → ИИ → «Где работает ИИ» = «Видеокарта»**.
* Если видеокарта занята игрой, часть ИИ уходит в процессор. Закрой лишнее или выбери нагрузку «Лёгкая».
* Ответ можно отменить: скажи «стоп» или нажми `Ctrl+Alt+X`.

**Отвечает на другом языке или «мусором».**
Скажи «Джарвис, проверь себя». Джарвис сам проверяет ИИ при запуске и, если надо, перезапускает Ollama в
безопасном режиме. Проверь, что **Настройки… → Основные → Нагрузка → «Экономия видеопамяти»** выключена.
Не помогло — выбери нагрузку «Лёгкая» и пришли диагностику (раздел 9).

**ИИ молчит / «Ollama не отвечает».**
Самодиагностика → «Исправить». Или Пуск → «Ollama», потом перезапусти Джарвиса. Недостающее можно докачать:
Пуск → Джарвис → **«Докачать компоненты»**.

**Срабатывает сам по себе.**
* На короткие фразы без имени — сними лишние галочки в «Команды без имени» (Настройки… → Основные).
* На имя из фильмов — понизь чувствительность микрофона.

**Закрыл не то окно.**
«Закрой» закрывает окно, которое было впереди, **когда ты начал говорить**. Надёжнее называть: «закрой хром».

**Не закрывает калькулятор / параметры.**
В 1.0.9 исправлено: приложения Windows закрываются как обычные окна.

**Ошибка про `cublas64_12.dll` / cuBLAS / cuDNN.**
Распознавание речи пытается работать на видеокарте без библиотек NVIDIA. Проще всего вернуть его на процессор:
«Настройки → Микрофон → Распознавание» → **процессор** (с 1.0.7 это стандарт). Хочешь видеокарту — поставь
библиотеки (около 1,1 ГБ):
`python\python.exe -m pip install nvidia-cublas-cu12==12.4.5.8 nvidia-cudnn-cu12==9.10.2.21` (из папки
`%LOCALAPPDATA%\Jarvis`).

**Не приходят тревоги / ошибки DNS.**
«Настройки → Интеграции → Воздушные тревоги → Проверить источники». В режиме «Авто» Джарвис сам переключается
между alerts.in.ua (нужен токен), siren.pp.ua и ubilling.net.ua. Если не открывается ни один, проблема в
интернете или DNS: перезагрузи роутер или поставь в Windows DNS 1.1.1.1 / 8.8.8.8.

**Грузит компьютер / Windows падает или зависает.**
Выбери нагрузку **«Обычная»** или **«Лёгкая»**. Сам Джарвис — обычная программа и «синий экран» напрямую
вызвать не может. Но ИИ сильно нагружает видеокарту, процессор и память, и это может выявить проблему с
драйвером или оперативкой. Если Windows падает:
1. Посмотри причину: «Просмотр событий» → Журналы Windows → Система, ищи ошибки **BugCheck** или
   **Kernel-Power** (или файлы в `C:\Windows\Minidump`).
2. Обнови драйвер видеокарты NVIDIA с сайта nvidia.com (чистая установка).
3. Проверь память: Пуск → «Средство проверки памяти Windows». Если включён разгон памяти (XMP/DOCP в BIOS),
   попробуй без него.
4. Пришли `jarvis.log`: в строчках «Ресурсы: …» видно, что творилось перед сбоем.

## 9. Как прислать логи разработчику

Самый простой способ: скажи **«Джарвис, собери диагностику»** (или значок у часов → **«Собрать диагностику
(архив)»**). На рабочем столе появится файл **`Jarvis-диагностика-….zip`**. Пришли его разработчику.

В архиве: журнал Джарвиса (`jarvis.log`), журнал Ollama (`server.log`), сведения о видеокарте (`nvidia-smi`) и
настройки **без паролей и ключей**. Ничего никуда не отправляется само — файл просто лежит на рабочем столе.

Вручную:

* Журнал Джарвиса: нажми `Win+R`, вставь `%LOCALAPPDATA%\Jarvis\logs` и нажми Enter. Нужен `jarvis.log` (и
  `crash_*.txt`, если есть).
* Журнал Ollama: `Win+R` → `%LOCALAPPDATA%\Ollama` → файл `server.log`.

## 11. Для продвинутых

### Свои команды (commands.yaml)

Можно добавить свою команду-горячую клавишу. Создай файл `%LOCALAPPDATA%\Jarvis\commands.yaml`
(открой трей → «Открыть папку Jarvis», рядом с ней будет `%LOCALAPPDATA%\Jarvis`) и напиши в нём, например:

```
- id: my_mute_discord
  section: Мои команды
  scope: any
  phrases: ["выключи микрофон в дискорде", "дискорд мьют"]
  keys: ctrl+shift+m
  reply: ""
  example: дискорд мьют
```

* `phrases` — как ты будешь говорить. Пиши маленькими буквами, без знаков препинания, «ё» как «е».
* `keys` — какие клавиши нажать (`ctrl`, `alt`, `shift`, `win`, буквы, `f1`…`f12`, `enter`, `left`…).
* `scope: browser` — только когда впереди браузер, `any` — в любом окне.
* `reply` — что ответить (`""` — молча). `example` — пример для списка «Что я умею».
* Если `id` совпадает со встроенной командой, твоя заменяет встроенную.

После правки перезапусти Джарвиса. Встроенные команды лежат в `jarvis\commands.yaml` в папке программы, можно
подсмотреть формат там.

### Где что лежит

| Что | Где |
|---|---|
| Программа, модели, голоса | `%LOCALAPPDATA%\Jarvis` |
| Твои настройки | `%LOCALAPPDATA%\Jarvis\settings.local.yaml` |
| Свои команды | `%LOCALAPPDATA%\Jarvis\commands.yaml` |
| Заметки, задачи, память | `Документы\Jarvis` |
| Бэкапы | `Документы\Jarvis\Backups` |
| Логи | `%LOCALAPPDATA%\Jarvis\logs` |
| Журнал Ollama | `%LOCALAPPDATA%\Ollama\server.log` |

## 12. Удаление

**Пуск → Джарвис → «Удалить Джарвис»** (или «Параметры Windows → Приложения → Джарвис → Удалить»).

* Деинсталлятор задаст два вопроса: удалить ли заметки и память, и удалить ли настройки. Нажми **«Нет»**, если
  может быть, поставишь Джарвиса снова — тогда всё сохранится. «Да» — удалить насовсем.
* Программа **Ollama** и её модели (~5 ГБ) удаляются отдельно: «Параметры → Приложения → Ollama → Удалить».
