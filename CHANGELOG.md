# История изменений

Формат: [семантическое версионирование](https://semver.org/lang/ru/). Теги релизов — `vX.Y.Z`,
установщик в релизе — `JarvisSetup.exe`. Текст раздела версии показывается в окне обновления.

## [1.0.1] — 2026-10-17

### Изменено
- «Передать Люмо» теперь работает по почте: письмо на `lumo-jarvis@mail.grokbot.com` (адрес меняется в «Настройки → Интеграции»). Тема начинается с «[Джарвис]», в письме задача и контекст (активное приложение, недавний разговор), снимок экрана и файл идут настоящими вложениями (до 15 МБ).
- Основной способ отправки: Gmail API через кнопку «Подключить Google». Это один вход для отправки писем и будущей синхронизации через Google Drive. Доступ хранится в диспетчере учётных данных Windows.
- Запасной способ: свой Gmail и пароль приложения (SMTP, smtp.gmail.com:465).
- Webhook остался как дополнительный способ для опытных, по умолчанию выключен.
- Если отправка не настроена, Джарвис коротко скажет об этом и откроет вкладку «Интеграции». После отправки: «Передал Люмо.»
- Как и раньше, Люмо получает задачу только по твоей явной команде и после подтверждения «Отправить?».

## [1.0.0] — 2026-10-17

Первый релиз.

### Основное
- Голосовой ассистент «Джарвис» на русском, полностью локально: Whisper (распознавание), Ollama (ИИ), Piper (голос).
- Активация по имени («Джарвис») с автоматическими падежами и вариантами, или push-to-talk.
- «Своё лицо» (лицо по умолчанию): картинка оживает в WebGL почти без искажений. Голова слегка покачивается, глаза моргают и светятся, рот мягко и симметрично приоткрывается по речи, есть лёгкие голографические сканлинии. Цвета: «Авто» (своя картинка как есть), под голограмму или оригинальные. При первом запуске Джарвис один раз предложит выбрать своё лицо. Метки лица находятся автоматически (mediapipe), а если не нашлись, их можно отметить в калибровке. Картинка хранится только локально.
- Стиль лица на выбор. 3D-голова на Three.js/WebGL: 3D-скан Lee Perry-Smith (CC BY 3.0), без шеи, двухцветный край, светящиеся глаза с кольцами радужки, нейро-вены, сеть узлов, bloom, челюсть по речи и моргание. Если WebGL недоступен, автоматически включается 2D-голова на QPainter. Также журнал диалога, работа из трея и автозагрузка.
- Режимы: рабочий, игровой (авто при полноэкранной игре, освобождение видеопамяти), ночной (по расписанию).
- Стилизация голоса «ИИ из Железного человека» (без клонирования чужих голосов).

### Навыки
- Музыка и видео: YouTube / YouTube Music (как приложения Chrome), медиаклавиши, поиск.
- Заметки под диктовку, задачи и напоминания с естественными датами, таймеры.
- Запуск игр (Steam, Epic) и программ по названию, поиск файлов.
- Ответы из интернета с источниками, погода (Open-Meteo), калькулятор и конвертер.
- Долговременная память, понимание экрана, помощь в играх.
- Код для Arduino / ESP32 / ESP8266 / STM32, 3D-модели (OpenSCAD, CadQuery → STEP).
- Telegram (чтение и отправка с подтверждением), умный дом (MQTT, HTTP, Home Assistant).
- Переводчик и режим синхронного перевода, диктовка в любое окно.
- Температура ПК с предупреждениями, воздушные тревоги по Сумской области.
- Переключение аудиоустройств, таймер выключения ПК.

### Надёжность
- Самодиагностика («Джарвис, проверь себя») с кнопками исправления.
- Ежедневный бэкап заметок, задач, памяти и настроек; восстановление.
- Пауза микрофона (Ctrl+Alt+M) — поток с микрофона действительно закрывается.
- Проверка обновлений через GitHub Releases (раз в сутки, установка только с согласия).
- Полное окно настроек — править файлы конфигурации не нужно.
- Синхронизация заметок, задач и памяти между ПК через общую папку (без секретов, с бэкапом перед слиянием).
- «Передать Люмо» — отправка задачи облачному ассистенту только по команде и после подтверждения.
- Отчёты о сбоях (`logs\crash_*.txt`) и сторож с автоперезапуском (не более 3 раз за 10 минут).
- Автоматическая миграция старых файлов настроек, защита от повреждённых настроек.
- Установщик: всё ставится в `%LOCALAPPDATA%\Jarvis` без прав администратора, обновление поверх с сохранением данных.
